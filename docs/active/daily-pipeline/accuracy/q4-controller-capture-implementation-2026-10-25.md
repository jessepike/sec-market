unexpected-status and redirect diagnostics, with a 2,000,000-byte response bound. It
retains the original raw observation and source-bound wrapper before classifying content.

JavaScript MIME type are required for capture. HTML, JSON, other charsets, empty bodies
and failed transport remain diagnostic failures. Missing response metadata stays unknown.

JavaScript MIME types are `text/javascript`, `application/javascript`, `text/ecmascript`
and `application/ecmascript`, with no charset or UTF-8 only. Raw bytes are retained;
there is no decompression, charset guessing or execution. Capturing all six scripts still

report. Actual attempted requests, including failed transport, must have ordered,
same-day request clocks. A final in-flight response cannot bypass the completion guard.
