What this site covers

12 domains, 74 tracked suppliers. Adding or dropping a domain or a supplier is a data change, not a promise about who belongs in the market.

Endpoint and XDR — Endpoint detection and response and extended detection and response platforms.
Security operations (SIEM/SOAR) — Security information and event management, and security orchestration, automation and response.
Managed security and MDR — Managed detection and response and outsourced security operations.
Network and SASE — Network security, secure access service edge, and secure service edge.
Cloud security — Cloud-native application protection platforms and cloud security posture management.
Identity — Identity and access management, privileged access management, and identity governance.
Data security — Data security posture management, data loss prevention, and backup and resilience treated as security.
Vulnerability and exposure management — Vulnerability scanning, exposure management, and attack-surface management.
Application security — Application security testing and software-supply-chain security.
Email security — Email security and business email compromise protection.
OT and IoT security — Operational-technology and industrial IoT security.
AI security — Security products for AI systems, covered as a market — who is buying whom and what is reported as revenue, not as news.
Not covered
Daily security news, vulnerabilities, and breaches as events
Product reviews and technical evaluations
Investment advice
Physical security, guarding and access-control hardware as a market
Governance, risk and compliance platforms that are not themselves a security-domain product
Insurance and cyber-insurance underwriting
Security domains outside the twelve listed above
