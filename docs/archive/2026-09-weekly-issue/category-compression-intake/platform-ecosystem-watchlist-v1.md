# 2. Why Cloudflare is strategically different

- Cloudflare sits in the traffic path at global scale. That creates context and an enforcement point across Internet-facing applications, APIs, users and increasingly AI/MCP traffic.

- It is simultaneously a security company and a developer/compute platform: Workers, Agents, Sandboxes, MCP infrastructure and Agent Cloud let it host autonomous systems as well as secure them.

- Its security portfolio now spans application/API security, DDoS/bot, SASE/Zero Trust, DLP/CASB, browser controls, AI Gateway, AI Security for Apps, MCP governance and managed vulnerability discovery/remediation.

- Cloudflare's architecture is naturally multi-cloud and model-agnostic. That may become more valuable as enterprises resist being trapped inside a single hyperscaler or model provider.

- The strategic gap versus Microsoft/Palo/CrowdStrike remains endpoint depth, privileged identity, broad SOC/XDR ownership and traditional enterprise security sales/channel reach. Partnerships or acquisitions could close those gaps.

# 3. Providers previously underweighted

**Fortinet:** Massive network-security install base and channel matter. FortiSOC now compresses six SOC functions into one agentic platform, while the Virtue AI acquisition adds AI runtime protection, agent red teaming and continuous AI validation. Fortinet is particularly relevant in mid-market, distributed enterprise and SLED.

**Check Point:** Still has a large installed base and prevention heritage. Its Daybreak integration now extends from frontier-model access into find → validate → remediate workflows. It may be less fashionable than Palo/CrowdStrike but should not be excluded from the platform race.

**Netskope:** Strong SSE/data-security position with an increasingly coherent AI security suite: Agentic Broker, AI Gateway, AI Guardrails, AI Red Teaming and MCP controls. A credible competitor where data + access + AI traffic converge.

**Okta:** The identity market is not automatically owned by Palo/CyberArk or Microsoft. Okta for AI Agents treats agents as first-class identities and is pushing into agent SSO, agent-to-agent connections, tool-call governance and short-lived credentials.

**ServiceNow:** Not a security sensor platform, but potentially one of the most important action/orchestration layers. As security becomes autonomous, governed change, workflow, approvals, CMDB/context and remediation orchestration become strategic.
